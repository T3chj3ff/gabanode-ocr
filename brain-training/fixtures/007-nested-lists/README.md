# Fixture 007: Deeply Nested Lists

**Purpose:** Test list nesting up to 5+ levels deep.

**Document Type:** Outline or specification with nested lists (procedural steps, hierarchical content).

**Expected Complexity:** Medium (85%+ target).

**Acceptance Criteria:**
- Extraction: ≥85%
- Healing: ≥80%
- Combined: ≥82%

**Brain should:**
- Preserve nesting levels accurately (indentation)
- Maintain ordered/unordered distinction at each level
- Keep items in sequence
- Not flatten or lose nesting
