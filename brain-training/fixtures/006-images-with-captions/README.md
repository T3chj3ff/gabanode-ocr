# Fixture 006: Images with Captions

**Purpose:** Test image extraction and caption association.

**Document Type:** Document with multiple images (charts, photos, diagrams) with captions and figure references.

**Expected Complexity:** Medium-high (85%+ target).

**Acceptance Criteria:**
- Extraction: ≥85%
- Healing: ≥85%
- Combined: ≥85%

**Brain should:**
- Identify images and extract captions
- Use meaningful image descriptions (not "image")
- Preserve caption text
- Handle figure references (Figure 1, Fig. 2, etc.)
- Add alt text in healing phase based on captions
